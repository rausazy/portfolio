# Zyrha Alliah Rausa — Portfolio

A static HTML/CSS/JavaScript portfolio designed for free hosting such as GitHub Pages.

## Run locally

Open `index.html` in a browser.

For the smoothest local preview, you can also use VS Code + Live Server.

## Before publishing

1. Replace the `YOUR PHOTO` placeholder in `index.html` with your own photo.
2. Put your résumé PDF at `assets/resume.pdf`.
3. Replace the LinkedIn and GitHub `href="#"` links.
4. Replace `your.email@example.com` with your real email.
5. Replace project placeholder areas with real screenshots.
6. Review the project descriptions and adjust anything that needs to match your final résumé.

## GitHub Pages

Create a public repository named:

`YOUR-GITHUB-USERNAME.github.io`

Upload the contents of this folder to the repository. In GitHub:

Settings → Pages → Deploy from a branch → select `main` and `/ (root)`.

Your portfolio will then be available at:

`https://YOUR-GITHUB-USERNAME.github.io/`

No paid hosting is required.
